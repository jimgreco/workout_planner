Forge Support

For Forge web and iOS beta testers.

Report An Issue

If you can open the app, use Send Feedback from the account menu. On iOS TestFlight builds, you can also send feedback through TestFlight.

Include These Details

  • Whether the issue happened on web or iOS.
  • The sign-in provider you used.
  • The build label shown in the account menu.
  • Any Request ID shown in an error message.

Privacy

Do not include provider tokens, app session tokens, or private workout notes unless you choose to share them. See the Privacy Policy for more detail.
